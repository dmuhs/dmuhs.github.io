soot.css is a classless CSS stylesheet that aims to be lightweight, opinionated, and flexible. It is meant as a drop-in stylesheet for small and medium-sized websites, and it can be adjusted through CSS variables. It was inspired by concrete.css, new.css, and countless brutalist websites, and it is available on GitHub and npm.
